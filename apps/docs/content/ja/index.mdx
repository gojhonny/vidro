# はじめに

Vidro は宣言的な環境コンパイラです。一つのプロジェクト設定が、リポジトリに必要な環境ファイルを表します。

```text
.vidro/<project>.vidro
```

このファイルがソース・オブ・トゥルースです。Vidro はシークレットマネージャではなく、dotenv ローダだけでもありません。

## 状態

Vidro はプレアルファです。公開パッケージはまだありません。CLI の実行ファイル名は `vidro` で、内部パッケージ `@vidro/cli` は private です。`vidro init` や `vidro generate` はスキャフォールドとして存在します。未実装である旨を表示して終了します。

このドキュメントは次の二つを分けています。

- **設計上の意味** — Vidro が定める言語と製品の振る舞い。
- **現在の振る舞い** — このリポジトリが今日実際に実行すること。

設計上の出力パスは[環境](/language/environments)にあります。現在の CLI はそれらのファイルを書きません。

## Vidro が担うこと

コンパイラが実装されたとき、Vidro は環境ファイルの契約を担います。非公開の外部値、出力の生成、必須値の検証、そして `src/env.ts` のような二重の実行時検証が不要になるだけの fail-fast です。

アプリケーションは、すでに妥当な設定を消費します。
