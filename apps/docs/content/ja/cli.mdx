# CLI

`@vidro/cli` は `vidro` バイナリを公開します。認識されるコマンドは次のとおりです。

| コマンド | 想定する役割 | 現在の振る舞い |
| --- | --- | --- |
| `init` | リポジトリを検出し `.vidro/` を作る | 未実装。終了コード 1。 |
| `generate` | Vidro ソースを環境出力へコンパイルする | 未実装。終了コード 1。 |
| `validate` | ソース、参照、解決済み設定を検証する | 未実装。終了コード 1。 |
| `check` | ソースと管理対象出力のずれを検出する | 未実装。終了コード 1。 |
| `show` | 外部値を隠した解決済み設定を表示する | 未実装。終了コード 1。 |

未知のコマンドも一覧を表示したあと 1 で終了します。`--help` は同じ一覧を表示して 0 で終了します。

`vidro show` は外部値を隠す仕様です。その隠蔽は未実装です。公開 npm パッケージはないので、`npx vidro` はまだインストール経路ではありません。
