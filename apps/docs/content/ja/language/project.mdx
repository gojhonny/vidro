# プロジェクト

すべての Vidro ファイルはプロジェクト名から始まります。

```css
project: "langdrift";
```

名前は文字列です。設定を識別し、規範的なソースパスは `.vidro/<project>.vidro` です。生成されるコンパイラ状態は、存在するとしても `.vidro/.generated/` にあり、ソースファイルにはありません。

LangDrift は最初に想定している統合先です。その統合はこのリポジトリではまだ実装されていません。
