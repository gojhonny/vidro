# 外部の値

シークレットの値を、追跡される Vidro ソースへコピーしてはいけません。シークレットは外部参照です。

```css
RESEND_API_KEY: $RESEND_API_KEY;
```

両側は同じ名前を使います。参照は、値が Vidro ファイルの外から来ることを記録します。シークレットそのものは保存しません。

その参照を解決する順序——プロセス環境、無視された env ファイル、CI、デプロイ先——は未決です。`NEXT_PUBLIC_` や `VITE_` のようにクライアントへ同梱される値は、この参照だからといって機密にはなりません。
