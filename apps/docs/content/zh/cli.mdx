# CLI

`@vidro/cli` 提供 `vidro` 可执行文件。它识别这些命令：

| 命令 | 预期作用 | 当前行为 |
| --- | --- | --- |
| `init` | 检测仓库并搭建 `.vidro/` | 未实现。退出码 1。 |
| `generate` | 把 Vidro 源编译成环境输出 | 未实现。退出码 1。 |
| `validate` | 校验源、引用和解析后的配置 | 未实现。退出码 1。 |
| `check` | 检测源和受管输出之间的漂移 | 未实现。退出码 1。 |
| `show` | 显示解析后的配置，并遮住外部值 | 未实现。退出码 1。 |

未知命令也会在打印命令列表后以 1 退出。`--help` 打印同一份列表并以 0 退出。

`vidro show` 的设计是遮住外部值。遮盖还没有实现。没有已发布的 npm 包，所以 `npx vidro` 还不是安装路径。
