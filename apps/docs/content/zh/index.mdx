# 介绍

Vidro 是声明式环境编译器。一份项目配置描述仓库需要的环境文件。

```text
.vidro/<project>.vidro
```

这个文件是唯一事实来源。Vidro 不是密钥管理器，也不只是 dotenv 加载器。

## 状态

Vidro 处于 pre-alpha。公开包尚未发布。CLI 的可执行文件名是 `vidro`，内部包 `@vidro/cli` 是私有的。`vidro init` 和 `vidro generate` 这类命令目前只是脚手架：它们会说明尚未实现，然后退出。

本文档区分两件事：

- **设计语义** — Vidro 规定的语言和产品行为。
- **当前行为** — 这个仓库今天实际会运行的内容。

设计上的输出路径写在[环境](/language/environments)。当前 CLI 不会写出这些文件。

## Vidro 将负责什么

编译器实现之后，Vidro 应成为环境文件的契约：私有外部值、输出物化、必填值校验，以及足够的快速失败检查，使应用不再需要第二套运行时校验，例如 `src/env.ts`。

应用应消费已经有效的配置。
