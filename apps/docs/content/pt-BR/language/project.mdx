# Projeto

Todo arquivo Vidro começa com um nome de projeto:

```css
project: "langdrift";
```

O nome é uma string. Ele identifica a configuração, e o caminho canônico da fonte é `.vidro/<project>.vidro`. O estado gerado do compilador, quando existir, fica em `.vidro/.generated/`, não no arquivo fonte.

LangDrift é o primeiro alvo de integração pretendido. Essa integração ainda não está implementada neste repositório.
