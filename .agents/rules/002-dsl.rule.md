# 002 — DSL stability

Scope: `packages/language`, parser, semantic compiler.

Preserve these semantics unless the owner explicitly changes them:

- `PATH` belongs to a target.
- Environment names are arbitrary identifiers.
- `default` maps to plain `.env`.
- `KEY;` means required/unresolved.
- `KEY: "";` means explicitly empty.
- `KEY: "value";` means literal.
- `KEY: $KEY;` means external.
- External secret references use the same key name on both sides for now.

Do not add keywords for common environment names such as development, production, preview, staging, test, or qa.
